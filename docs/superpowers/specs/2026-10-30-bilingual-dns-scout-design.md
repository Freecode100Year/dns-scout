# DNS Scout 简体中文 / English 设计

## 目标

在现有 Windows DNS Scout 桌面应用中提供简体中文和英文界面，并发布一个可切换语言的 Windows x64 便携 EXE。首次启动根据系统 UI 语言选择界面语言，用户可随时切换；选择保存在 `%LOCALAPPDATA%\\DNSScout`。DNS 测试、网卡设置、权限边界和现有数据格式保持不变。

## 方案

- 单个可运行时切换语言的 EXE（用户选择）。
- 分别构建中文和英文两个 EXE：资产重复，用户无法在程序内切换。
- 只根据系统语言自动选择：无法满足用户主动切换的需求。

采用第一种方案，避免重复发行包并支持用户覆盖系统默认值。

## 实现范围

- 将窗口标题、表单、按钮、表格列、状态提示、验证错误、对话框和 CSV 标题放入中英文消息表。
- 在窗口顶部提供语言选择，切换后立即刷新界面文本，不重置当前测速数据或输入。
- 首次启动按系统 UI 语言选择，无法识别时默认为简体中文；保存显式选择到 DNS Scout 的本地设置文件。
- 地区选项使用对应语言显示，同时映射至现有数据源 slug；外部返回的运营商/地区原文保留。
- README 说明语言切换、偏好文件和便携 EXE 使用方法。

## 验证与发布

- 先增加测试，确认语言默认、偏好读写、地区映射和切换后的可见文案。
- 运行完整 Python 单元/UI 测试以及 PowerShell 配置隔离测试。
- 使用 Windows Python + PyInstaller 构建单文件 EXE，在 Wine 下运行 `--smoke-test`，检查文件格式和 SHA256。
- 以 `v0.1.0-preview.3` 发布 Windows x64 EXE、校验和及使用说明；不声称通过真实 Windows 11 网卡/UAC 验收。

## 限制

发布包保持未签名。Linux/Wine 冒烟检查不能代替 Windows 11 实机的网卡配置与 UAC 验收。仓库已有未跟踪 `.github/workflows/build.yml`，实施时保留其内容，除非发布验证证明必须调整。
