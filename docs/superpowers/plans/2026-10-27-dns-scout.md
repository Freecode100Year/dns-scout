# DNS Scout Implementation Plan

Goal: Chinese portable Windows 11 x64 DNS benchmark utility using publicdnsserver.com.
Architecture: standard-library Tkinter UI, concurrent DNS socket probes, isolated PowerShell network configuration, Windows CI/PyInstaller release.
Tech Stack: Python 3.12, Tkinter, dnspython, BeautifulSoup, PyInstaller.
User delegated implementation choices and execution on 2026-10-27.

## Constraints and design
Read-only benchmarking by default. Website timings are metadata, never local measurements.
Query A records for example.com, www.microsoft.com, www.baidu.com using UDP with TCP fallback.
Rank by success ratio then median successful latency. Failed requests remain in denominator.
Support IPv4/IPv6 candidates, region selection, custom IPs, cancellation, CSV.
Explicit adapter selection and local confirmation before system changes. Save initial per-family
static/DHCP state before mutation; restore the same adapter by GUID and verify readback.
Only configuration helper elevates; no shell interpolation of user strings.
Cache fetched lists for offline use with explicit age. No bundled scraped database.

## Review focus
Malformed HTML must fail explicitly; partial/failed DNS responses must not rank as successes;
DNS changes must preserve rollback state; cancellation must keep UI responsive;
Windows packaging must contain Tcl/Tk and work without installed Python.
